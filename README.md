# chip8_FPGA

CHIP-8 interpreter for an Arty Z7-20 FPGA board (early stage: RAM walker driving the LEDs).

- `chip8_source/RTL/`: `chip8_top.v`
- `chip8_source/constraints/`: board XDC
- `chip8_source/memory/`: font and `snake` ROM images
- `CHIP8.dpf`: Altair DSim project

Status: active (started 2025-11).
